# Hz · 记录与连接

个人博客、知识库、项目展示与想法随记。暗色界面，鼠标响应线条背景，支持减少动态效果。

## 访问网站

在本仓库 Settings → Pages 中查看 GitHub 返回的实际发布网址。网站通过 main 分支根目录发布，无需本地电脑保持开机。

## 更新内容

当前为静态网站首版，文章、知识笔记、项目及短想法存储在 `app.js` 开头的 `articles`、`notes`、`projects`、`seedIdeas` 数组中。修改并提交到 main 后，GitHub Pages 自动发布新版本。

目前内容为明确标记的示例。尚无文章上传后台、Markdown 自动导入或云端想法同步。页面中的“保存到本机”只保存到当前设备、当前域名下的浏览器存储，不会发布到网站。不能用于跨设备同步。

若要新增博客文章，提供唯一 id、type、title、category、date、desc 和 HTML 正文 body，并加入 articles 数组。目前博客分类固定；首页精选指向 garden，更换精选时应同步修改点击目标和文案。真实文章应调整相应示例标记。

## 文件

- `index.html`：页面骨架
- `style.css` / `dark.css`：布局与暗色主题
- `app.js`：示例内容、交互和背景动效
- `.nojekyll`：直接发布静态文件

本仓库不包含账号凭据。文章与项目目前不代表站主的真实经历或成果。
